So verwenden Sie das Portal

Die folgenden Schritte geben Ihnen einen kurzen Überblick über die wichtigsten Funktionen.

1

Einrichtungen finden

Öffnen Sie das Einrichtungsverzeichnis. Suchen Sie nach Name, Ort oder Postleitzahl. Über die Filter können Sie die Ergebnisse zusätzlich nach Angebot und Bundesland eingrenzen.

2

Einrichtungen auswählen

Wählen Sie in der Ergebnisliste eine oder mehrere Einrichtungen aus. Die Auswahl wird für die Vorbereitung einer Nachricht übernommen. Sie können die Auswahl jederzeit ändern.

3

Einrichtungsdaten pflegen

Benutzer mit entsprechender Berechtigung können neue Einrichtungen anlegen, vorhandene Angaben bearbeiten oder Datensätze deaktivieren. Pflichtfelder sind im Formular mit einem Stern (*) gekennzeichnet.

{% if can_edit %} {% else %} Dieser Bereich ist nur mit entsprechender Bearbeitungsberechtigung verfügbar. {% endif %}
4

E-Mail vorbereiten

Wechseln Sie zur E-Mail-Zentrale. Die Adressen der ausgewählten Einrichtungen werden übernommen. Ergänzen Sie Betreff und Nachricht und wählen Sie „E-Mail vorbereiten“. Ihr lokales Mailprogramm öffnet sich; der Server versendet die Nachricht nicht selbst. Die Empfänger werden im BCC-Feld eingetragen.

5

Versandhistorie aufrufen

Im Bereich Versandhistorie ist die vorgesehene Übersicht früherer Versandvorgänge erreichbar. Die Anzeige ist in der aktuellen Projektversion noch nicht an eine Historien-Schnittstelle angebunden.

Hinweis zu Benutzerrechten

Welche Funktionen Ihnen zur Verfügung stehen, hängt von Ihrer Benutzerrolle ab. Wenn ein Bereich nicht angezeigt wird, fehlt möglicherweise die entsprechende Berechtigung.
